# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),

## [0.1.0] - 2025-10-11

### Added
- Initial release of Trackify
- GitHub pull request tracking and analysis
- WakaTime integration for time tracking
- Clockify integration for time logging
- CLI commands: `trackpr` and `get-pr-summary`
- Pull request summary generation with commit categorization
- Rich terminal UI with progress indicators
- Environment variable configuration
- Comprehensive documentation
- Unit tests with VCR for API mocking
- Type hints and MyPy support
- Pre-commit hooks for code quality

### Features
- Track time spent on GitHub pull requests
- Generate detailed PR summaries
- Log time entries to Clockify automatically
- Beautiful terminal output with Rich
- Configurable logging levels
- Date-based time tracking queries

### Documentation
- README with installation and usage instructions
- Architecture documentation
- Quick start guide
- API key setup instructions
- Troubleshooting guide
